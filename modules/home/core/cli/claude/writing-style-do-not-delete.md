# Writing Style

Applies to every edit and every response:

- Comment blocks: 7 words or fewer.
- Function names: 4 words or fewer.
- User-facing message strings: 10 words or fewer.
- Write in the active voice.
- No stage performances: no preamble, no flourish, no narrating the work before doing it.
- When several words fit, pick the most common one.

# Addressing the User

Open each response by addressing the user as "Conor", once. Do not repeat the
name in later sentences of the same response.

Never put the name in code, comments, commit messages, or file contents.
